Homeostatic Seasons adds four seasons (each with three subseasons) to
Minecraft, each lasting 28 in-game days (configurable). The current season is
defined by the world time (using /time set 0 will reset to day 1 of spring).
Each season has its own changes; during the spring, biomes will mostly try to
match their original characteristics.

This mod was originally planned as a NeoForge port of Fabric Seaons with the
permission of the mod author. However, due to many delays, it has been decided
to make an independent season mod.

## Features

- Biomes use an improved temperature system that not only maps biomes, but
  also has better temerature smoothing across different temperature biomes.
  This enables weather changes like snowing and block freezing in the winter.
- Biomes will have different colormaps according to the current season. This is
  just a visual change and it'll not physically impact your world in any form.
- As with biome colormaps, show is added as a as a visual component outside of
  snowy biomes. This is done to not cause server lag associated with adding
  actual layers of snow. The goal of the mod is to make it playable on a
  reasonably powered machine.

### Seasonal Temperature
- Cold Biomes will have rain in the summer
- Temperate Biomes will have snow in the winter
- Tropical Biomes will have a steady season all year round
- Hot Biomes will have a rainy season in the winter
- Thunderstorms are more common from Late Spring to Mid Summer

Depending on the original temperature/precipitation of the biome, this behavior can change.
